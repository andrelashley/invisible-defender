## Acceptance

The system will be considered complete when real-time, synthetic data produces visualizations and meaningful insights that can be consumed and understood by someone watching or analyzing the current match.

A synthetic match can be started, paused, resumed, and replayed.

Match events and positional data update the visualization in real time.

The system identifies at least three types of defensive contributions.

Every identified contribution links to supporting event and positional data.

Viewers can explore how a defender's position changes passing opportunities.

Foundry generates grounded explanations for casual viewers and analysts.

The application runs locally and is deployable to Azure Container Apps.

Relevant automated tests pass.
